# 1.1.0 验证记录

日期：2026-10-16。目标环境：Minecraft 1.20.1、Forge 47.4.10、Java 17。

## 已完成

- JDK 17 完整 Gradle 构建成功，包含 `reobfJar`；产物为 `build/libs/mclogin-1.1.0.jar`。
- `securityChecks` 通过 49 项断言：重置授权 20 项、账号存储 29 项。
- 授权检查覆盖未验证拒绝、跨 UUID、重复验证、单次消费、旧回调、重连后的请求隔离、各阶段过期和撤销。
- 存储检查覆盖有效账号往返、根结构缺失、非法 UUID、缺失密码字段、加载失败后的缓存保留及禁止覆盖、修复后重载、空库往返和 1.0.0 空库升级。
- 中英文语言键一致，源码引用的消息键完整；Git diff 无空白错误。
- 已检查 JAR 内版本为 1.1.0，并包含密码重置接口、授权服务和 UI 类。

复现命令（JDK 17）：

```powershell
.\gradlew.bat build --no-daemon --console=plain
```

本次最终构建使用已准备好的依赖缓存，加了 `--offline`。首次构建需联网下载依赖。测试中的账号文件和故障证据生成在 `build/regression-evidence/`，不提交到仓库。

## 尚未验证

- 本版本未启动真实 Minecraft 客户端/服务端，菜单外观、自动重开、铁砧输入步骤、音效及其他模组兼容性需要游戏内验收。
- 默认没有外部身份验证器；未进行真实验证服务的端到端密码找回测试。
- 构建与隔离断言通过不等于游戏运行验收完成。

接口接入和运行验收清单见 [PASSWORD_RESET_API.md](PASSWORD_RESET_API.md)。
