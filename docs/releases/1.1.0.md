# MCLogin 1.1.0 · 多版本模组与 Paper 插件

为 Minecraft 服务端提供注册、登录、改密、注销和原版界面认证。客户端无需安装 MCLogin 或资源包。

## 下载选择

| 环境 | 下载 | 安装 |
| --- | --- | --- |
| Forge / Fabric 六个目标版本 | `MCLogin-1.1.0-ports.zip`，或单独下载对应 JAR | 选择匹配游戏版本和加载器的文件放入 `mods/`；Fabric 另装对应 Fabric API |
| Paper 六个目标版本 | `mclogin-paper-spigot-1.1.0.jar` | 放入 `plugins/` |
| Paper 插件及随包说明 | `MCLogin-1.1.0-plugin-compat.zip` | 解压后安装其中的 MCLogin JAR |
| 原 Forge 1.20.1 | 保留仓库根工程构建 | `./gradlew build` 生成 `mclogin-1.1.0.jar` |

目标游戏版本：**1.20.4、1.20.6、1.21.1、1.21.4、1.21.8、1.21.11**。1.20.4 使用 Java 17，其余使用 Java 21。12 个模组文件名含 Minecraft 版本及加载器，Paper 六版本共用一个插件文件。下载后使用随附 `SHA256SUMS` 核对。

## 主要内容

- 保留 Forge 1.20.1 基线与历史，新增 12 个 Forge / Fabric 独立工程及 Bukkit 插件工程。
- 随机盐 PBKDF2、后台有界计算、防爆破、未认证活动限制和异常账号库保护。
- 原版箱子菜单、铁砧输入、倒计时；根据账号状态显示注册或登录。密码找回默认关闭，接入已绑定身份的外部验证器后才可使用。
- 插件接入 LuckPerms 权限、PlaceholderAPI、Bukkit 登录状态服务及同步认证事件；固定组合联调 EssentialsX、Vault、WorldEdit、WorldGuard。
- 重复认证插件触发锁定，须保留一种认证系统并重启；不导入其他认证插件密码库。
- 重新整理首页、版本总览、各版本依赖、安装、配置、账号迁移、安全和开发接口。

## 验证与边界

12 个移植工程均构建并通过每工程 49 项安全断言及开发服务端协议检查；1.20.4 和 1.21.11 的 Forge / Fabric 另有正式成品独立服务端检查。根 Forge 1.20.1 仍按原基线记录，不声称已完成真实游戏验收。

Paper 同一最终 JAR 在六个固定组合各通过 56 项检查，加最小依赖 18 项与 AuthMe 冲突 4 项，总计 **358 项运行检查**；构建断言 **85 项** 单独计。插件 JAR SHA-256：`31cb8a2021c5e69d54ec12595be433cc4385e14a3bd3cbf21efe72f229312907`。

Spigot 仅 API 编译兼容，缺少 Paper 铁砧 API 时回退命令。Geyser/Floodgate/ViaVersion 共同启用已检查，未完成真实基岩或跨协议客户端验收。不声明 Folia、混合核心、所有第三方插件或生产压力兼容。发布文件不含测试夹具、第三方插件、账号库及运行日志。

安装前停服备份；保持可信 UUID 与正确代理转发，限制后端直连。配置路径、固定依赖和验证证据见仓库文档。
